## 0. 项目自述（叙述体，约 1,100 字）

**为什么做这个东西**

我刷题时最烦的不是题目难，而是"打不开"。地铁进隧道，页面转圈，刚才做了一半的题没了；换台设备，签到记录清零；想看一眼题解，弹窗说"今日免费额度已用完"；想系统补一下语法，找到的课程是文档搬运，第一页讲完变量，第二页直接上模板元编程。一个本来就靠连续投入才有回报的事，被这些摩擦消耗掉了大半动力。所以后来我干脆自己做了一个：把内容全部塞进安装包里，装完就是完整的，不联网也能用，没有账号、没有广告、没有额度。

**它到底是什么**

它不是刷题网站的壳，也不是题库 App 的换皮。它是一个**内容自包含**的练习场：27,933 道题、每道题配一份题解、四门语言的入门课程、24 个高频考点专题、72 组面试主问题（带追问链），全部是静态文件，随包发布。你把网络关掉，它除了不能下载新版本以外，功能一个不少。

**功能是怎么串起来的**

它按"练"的动线设计，而不是按"逛"的动线。打开是今日状态和继续上次的位置；进题库按题号、标题、题型三路检索，搜空了会告诉你哪些题型真实存在，不会丢一个空白列表给你；点开做题，四语言参考代码放在手边，卡住了往上一翻就是思路和复杂度；做错的自动进错题本，想收藏的点星，感想写在笔记里。某个专题连续栽跟头，就去专题页看那 24 个考点的模板和图解；看不懂模板里某一行语法，就跳去对应语言的课程章节——80 章、320 节，每节只有一屏多一点，配图、示例、易错点，看完能立刻回去接着做。面试前想突击，就去面试页按主题过一遍主问题，想深挖再展开"如果数据量到 10^9 呢"这类追问链。

这中间所有动作都会沉淀：打卡天数、AC 记录、收藏、错题、笔记，全在本地，做完题还会解锁成就和头像框。不是为了分享到朋友圈，是因为刷题是个反馈周期很长的活儿，得给自己一点看得见的东西。

**几个刻意的取舍**

第一，**不做在线评测**。真正的评测要服务器、要沙箱、要排队，那就必然要联网、要限流、要收费。这个 App 的"运行/提交"只做静态结构检查：括号配不配、头文件在不在、有没有 main、有没有踩常见语法坑，通过就记 AC。这是个明确的让步，我在应用描述里也照实写，不假装自己是 OJ——换来的是断网可用和零服务器成本。

第二，**内容由脚本生成，而不是手写进页面**。题库、题解、课程、专题全部来自 `tools/` 下的 Node 生成器，输出成静态 JS 分片。好处是数据口径一致、批量改文案不会漏、2.7 万道题的"输出格式"能一次重写成统一句式；坏处是仓库里不放生成产物（158MB），clone 后要先跑一遍生成脚本。

第三，**前端零依赖**。没有框架、没有打包器、没有 UI 库，原生 JS 加纯 CSS 变量做深浅双主题。因为这东西的目标寿命是"三年后还能打开"，而不是"这个月技术栈最潮"。

第四，**安装包大得有点不合理**。36MB，全量资源内嵌，安卓壳用 `shouldInterceptRequest` 把虚拟域名映射到本地 assets。这不符合"首包越小越好"的常识，但符合这个 App 的立身之本：装好即完整，飞机上、地铁里、信号差的出租屋里都能刷。

**做给谁**

准备校招社招算法面试的人；想把一门语言语法练到不假思索的人；通勤路上想刷两道但信号不稳的人；以及不想被"该续费了"反复提醒的人。它不追求日活、不做社交、不接广告，代码和内容都开源，谁都可以拿去改成自己的版本。

## 0.1 精简版（≤350 字）

刷题最烦的不是题难，是"打不开"：地铁进隧道页面转圈，换设备记录清零，看题解提示额度用完。所以做了 AlgoMaster——内容全塞进安装包，装完即完整，不联网、不注册、无广告。

它是自包含的练习场：27,933 道题各配题解（思路、复杂度、四语言代码）、四门语言 320 节微课、24 个考点专题、72 组面试主问题带追问链，静态文件随包发布，断网功能不减。

动线按"练"设计：题库三路检索→做题看题解→弱项进专题看图解→不懂的语法跳微课→面试前过追问链；打卡、AC、错题、笔记全存本地，做题解锁成就。

取舍是刻意的：不做在线评测，"运行"只做结构检查，换断网可用与零服务器；前端零依赖，图三年后还能打开；APK 36MB 全量内嵌，只为装好即完整。

## 4. 应用商店 · 完整说明（正式版）

**AlgoMaster 算法刷题 —— 一个不需要联网、不需要注册的算法练习场**

打开就能刷。没有开屏广告，没有会员墙，没有「每日限免 3 题」。全书 171MB 内容全部打包在安装包里，飞机上、地铁里、断网时照样用。

**■ 题库：27,933 道，够刷很久**

按 26 个算法题型分类（数组、二分、DP、图论、树、回溯、位运算……），分简单 / 中等 / 困难三档，共 8,615 / 14,897 / 4,421 道。支持题号、标题、题型三路检索，搜不到时自动推荐「真实存在的题型」，不会让你对着空白列表发呆。

**■ 题解：每道题都有**

不是只给答案。每份题解包含思路拆解、复杂度分析，以及 C++ / Python / Java / C 四语言参考实现。做题卡住时，往回翻一页就能对照。

**■ 课程：4 门语言 × 80 章 × 320 节微课**

C++、Python、Java、C 各 20 章，每章拆成 4 节短课。每节配 SVG 图解、可运行示例、语法对照表、要点清单和易错点提醒——不是文档搬运，是照着「看一遍就会用」的节奏写的。

**■ 专题：24 个高频考点**

双指针、滑动窗口、二分查找、动态规划、并查集、单调栈、树状数组、位运算……每个专题给出模板代码 + 图解演示 + 例题串讲。指针怎么移、网格怎么填、复杂度曲线谁快谁慢，全是画出来的，不是文字描述。

**■ 面试：72 组主问题，576 条追问**

按主题分组，主问题下面挂着真实面试里会出现的追问链（"那如果数据量到 10^9 呢？"）。只看主问题不会被追问淹没，想深挖再点开。

**■ 学习闭环：看得见的进步**

每日打卡、连续天数、AC 记录、收藏夹、错题本、笔记，全部本地保存。做完题解锁成就，头像框一档档开——不用分享到朋友圈，纯粹给自己一点正反馈。

**■ 关于「运行」按钮**

浏览器版和 App 版的「运行 / 提交」做的是**静态检查**（括号配对、头文件、main 函数、常见语法坑），通过即记为 AC。它不是在线评测机，不会真的编译执行你的代码——这样才敢完全离线、零服务器。

**■ 技术上的几个坚持**

- 零依赖：没有 React、没有 Vue、没有打包器。原生 JS + 纯 CSS 变量主题，首屏加载完就能用
- 双主题：深色 / 浅色跟随系统，也能手动切
- 手机优先：底部 Tab 导航、物理返回键接管（安卓）、代码块自动折行不裁字
- 数据本地：不收集任何信息，不请求任何第三方接口，没有账号体系

**适合谁**

正在准备校招 / 社招算法面试的人；想把一门语言的语法练熟的人；通勤路上想刷两道题但信号不好的人；以及不想被会员订阅反复提醒「该续费了」的人。
